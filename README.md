# Personal Portfolio Website

A full-stack portfolio website developed to showcase my profile, technical skills, projects, education, and contact information. The application allows visitors to learn about my work and submit queries through a contact form, with messages securely stored in MongoDB.

## Features

* Responsive and Mobile-Friendly Design
* Professional Portfolio Layout
* About Me Section
* Skills Showcase
* Project Showcase
* Education Details
* Contact Form
* Backend API Integration
* MongoDB Database Storage for Contact Messages
* Smooth User Experience Across Devices

## Installation

### Clone Repository

```bash
git clone https://github.com/Sai-Rohith-P/Personal_Backend.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file inside the backend folder and add:

```env
MONGODB_URI=your_mongodb_connection_string
PORT=5000
```
